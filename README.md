# E-commerce-Website
Selling Website – System Description  This Selling Website is a complete multi-vendor e-commerce platform designed to manage products, shops, orders, and users efficiently through dedicated panels. The system supports sellers, wholesalers, employees, and customers, each with role-based access and responsibilities.
